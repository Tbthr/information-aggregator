## 推特精选

• Browser Use + JEV = 浏览器操控速度质变：Browser Use 团队基于 JEV 模型推出 jev-ultrafast（19K+ stars），Google Flights 搜航班仅 7.1 秒。JEV 把页面元素编号成离散选择题，一次请求同时决策动作+目标——本质上把"大模型写长文操作网页"降维为多选题。已有开发者做了链上自动交易 demo（开源，跑 14 小时亏 300%，但架构清晰）。

• Muse by Meta 登顶美区 App Store，Shopify 官宣接入当天涨 13%。Personal Agent 品类被正式带火。但 Meta 风控严（几十年积累），非美国用户体验受限。Alexandr Wang（Scale AI）参与叙事。

• 阿里开源 OpenCodeReview（40.5K stars）——内部用了两年的 AI Code Review，"确定性工程 pipeline + AI Agent"混合架构，解决通用 Agent 做 Code Review 时漏审、定位漂移、质量不稳的老问题。

• 阿里 OpenCodeReview — 确定性 pipeline × Agent 混合架构做代码审查，内部两年实战后开源，40.5K stars。与 Akai 的"确定性 + LLM"混合执行思路同族。

• Mable Jiang 创立 Trasia，建在 Hyperliquid 上做亚洲向永续合约。Citi → 滴滴 → Multicoin Capital 合伙人 → 独立创业，crypto 圈核心人物动向。

• Muse 爆火叙事两条：一条讲 App Store 登顶 + Shopify 联动，一条讲 Alexandr Wang 如何"拯救 Meta"——Meta 为元宇宙烧 600 亿后换了个更贴近普通人的 Personal AI 故事。

• Browser Use × JEV 两条互为补充：一条讲技术原理（DOM 编号 → 离散多选题 → 一次请求），一条讲工程震撼（过去 GPT/Claude 操控浏览器太慢，JEV 把延迟从"等半天"压到秒级）。

• Rene — multiplayer-first iMessage agent，能浏览网页、写代码、购物、建站、做 slides。"text like a friend"定位，创始人用了 4 个月找办公室、准备会议。与 Muse 同属 Personal Agent 品类但切入点不同（iMessage vs Instagram）。

• Instinct 被描述为"OpenClaw for normal people"——personal AI agent 赛道持续升温。Assistant Benchmark 同期上线，评 71 个 AI 个人助手的 15 个维度（速度/记忆/邮件/研究/购物/权限等）。

• Instinct 网络效应——300K+ 次 Instinct-to-Instinct 协调，新增文件直传和改进通知。"与用户生活中最信任的人协调"是差异化叙事。

• Muse 开源生态浮现——GitHub 出现 3 个免费开源项目专为 muse.ai 设计，含 100+ Agent 任务模板库，试图把 Muse 从聊天工具升级为 Agent 工作流平台。

• 7 个 GitHub 搞钱工具合集——覆盖找资源/API/抓数据/跑模型/搭 Agent/做 AI 产品完整链路，Awesome（50.9 万+ Stars）领头。
