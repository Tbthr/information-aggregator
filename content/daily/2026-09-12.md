## 推特精选

• OpenAI 发布 Agents API，把 Codex 背后的 Agent harness 直接开放——Agent 基础设施公司需要重新审视护城河，"以前你自己搭的那套"现在变成了 OpenAI 的一等公民 API。来源: feed

• Kalshi 计划申请美国监管批准，推出约 60 种股票（Tesla、Apple、Nvidia 等）及 ETF 永续合约，支持全天候交易；若获批将成为美国首批受监管的单一股票永续合约。来源: WSJ via feed

• Cloudflare 发布 @cloudflare/computer，给每个 AI Agent 配一台云端"虚拟电脑"——文件系统 + 多执行环境，毫秒级启动，Agent 自己决定把命令派到哪个环境跑。来源: bookmarks

• Agents 进入生产环境——Schneider Electric、Vodafone、monday.com 等欧洲/中东企业正在构建 Agent 运行基础设施和运维模型。

• Binance bStocks 上线 3 个月累计交易量突破 300 亿美元，超一半 RWA 永续成交在币安；观点：RWA 的 killer app 可能不是资产上链，而是把全球资产变成 Crypto 可交易的 ticker。

• Senate Republicans 修订 Clarity Act；研究人员将攻击 Bitcoin/Ethereum 密钥的量子基准减半。

• Blockstream 拒绝向持有 Liquid Network 漏洞中 598.5 BTC 的黑客付款，称扣留资金是犯罪行为而非白帽安全工作。

• 沙特阿拉伯因伊拉克领土发射的无人机袭击关闭关键石油管道，加剧地区冲突扩大影响能源供应的担忧。

• 有人以 6TB Fable 数据集声称可接管 7 个中国/CIS 政府实体和 19 家中国头部公司（小米、华为、NIO、Minimax）——AI 数据安全警示。

• 跨公司多 Agent 被质疑为"自加复杂度"：同公司多 Agent 可理解，不同公司的意义何在？自身条件的约束不是真正的技术约束。

• Anthropic 被批评：将 154 页 Claude 武器化报告包装成 pre-IPO pitch，展示模型有多强大以争取更多投资和政府支持。

• Claude Code 系统提示词为最新模型削减约 80%——关于写 system prompts、skills 和 Claude.MD 的经验分享。

• AI 市场渗透率：整个 AI 行业仅捕获 $6T+ 知识工作者劳动力市场的不到 1%，即使最好的垂直领域（软件开发、客服）渗透率也极低。

• AI Engineering 最重要技能地图发布。

• Matrix Agent 公司架构：不是一个 Agent，而是一套能长期运行的 Agent 公司 OS——Agent 公司 = 多 Agent 编排 + 任务流转 + 工作成果可视化。

• GPT-Realtime-2 实时翻译音频：集成到 Chormex 后可即时翻译 YouTube 视频、直播、会议、演示中的音频。

• wanman.ai（第 14 款 vibe 产品）开源：让任何人在 AI Agent 团队帮助下零部署创办或接管"一人公司"，支持 Codex 调用 GPT image 2 自动创建设计师 Agent。

• 谢青池从 200+ 篇 AI 论文中挑出 36 项经典论文，附下载地址整理分享。
