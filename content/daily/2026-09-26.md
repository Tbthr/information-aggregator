## 推特精选

• Opus 5.5 前端能力全面碾压：一键生成产品宣传片（含代码生成的背景音乐），Remotion 框架被替代——"AE 动效设计师天塌了"的声音开始出现。同时 GPT-6 Astra 被评为明显不如 Opus 5.5。OpenAI Dev Day 下周二成关键节点。

• Together AI 发布 Jev 模型低成本训练教程：基于 Qwen3.5 4B，25 分钟 + ¥100（$17），3.8 万条 HuggingFace 公开数据集——Jev 类模型的训练门槛正在被推向"人人可复现"。

• Muse（Meta）注册通道被发现：通过 Grok Bot 远程桌面 → Chrome → muse.ai/join——与 Grok Bot 的差异化讨论开始升温。

• 《高性价比人生指南》开源书：GitHub 13K+ Star，601 条人生建议，每条附期刊论文和官方文件引用，末尾"说人话"翻译统计数字。覆盖裁员补偿、押金维权等实操场景——开源内容从技术领域扩展到生活决策。

• guizang-product-video-skill（GPT Skill）：基于代码库自动生成产品更新宣传片，读取组件、配色、logo 和素材，自动写文案 + 做动效。最亮点：音乐由 GPT 用 Python 代码生成。Opus 5.5 执行效果远超其他模型。

• Opus 5.5 vs Remotion：原作者已公开提示词，核心是"8-12 个 UI 元素变形动效"的 one-shot 生成——从框架编码到纯 prompt 驱动的动效制作，工具链断代正在发生。

• Browser Use × Jev 持续热门（与上期重叠）：jev-ultrafast 19K+ Stars，7.1 秒搜航班。链上自动交易系统开源（跑了 14 小时亏 300%，但架构惊艳）。

• Rene 发布（与上期重叠）：multiplayer-first iMessage Agent，四个月内测——Personal Agent 从单用户工具走向社交原生。

• Instinct 评价："OpenClaw for normal people"——正在帮用户的父亲设置，Personal Agent 开始触达非技术人群。

• Assistant Benchmark 上线：71 个 AI 个人助理 × 15 维度公开评分卡——Personal Agent 赛道首个标准化评测框架。

• Browser Use × Jev 持续爆发：团队基于 Jev 模型推出 jev-ultrafast，19K+ Stars，Google Flights 搜航班 7.1 秒完成——把页面可交互元素编成带编号的表，Jev 一次请求同时决定动作和目标元素，彻底改变了浏览器 Agent 的速度基线。

• Rene 发布：multiplayer-first iMessage Agent，像朋友一样发短信交互，内置浏览器、写代码、购物、建站、做幻灯片和图片——Personal Agent 赛道从"能力展示"进入"社交原生"阶段。

• Muse（Meta）购物体验实测：500 元预算买降噪耳机，先搜京东（要登录）→ 自动转华为电商 → 列出商品供选择——一个美国 App 对中国电商的熟悉度令人意外，Personal Agent 进入交易执行层。

• Raft 开源（Kimi CLI 前作者 Richard Qian）：Agent 协作平台源码公开，但不接受 PR，只接受 prompt request。GitHub 仓库是 release mirror，实际开发在私有仓。团队 3 位 AI co-founder，探索 Human×Agent 协作 Slack 新形态。值得关注的是"不接受 PR 接受 prompt request"这个开源模式创新。

• Nokia 开源 AnyJev：本地 Jev 需求的替代方案——基于已有 LLM 底座，零标签读出 choice/yes-no/score 和可设阈值概率。核心观点："与其再训 / 微调一个小决策模型，不如把决策留在已经在跑的开源 LLM 上"。

• Opus 5.5 one-shot 教程能力：用一句提示词生成完整的 ChatGPT/Transformer 原理教程，覆盖 Attention Is All You Need 核心机制——比大多数人工教程更清晰、更直观。AI 内容生产从"辅助写作"到"一次性高质量教学内容"。

• Browser Use × Jev 速度突破（重复出现，热度极高）：7.1 秒搜航班，离散多选题思路替代大模型长推理，DOM→编号表→Jev 一次决策。

• Instinct 个人 AI Agent：被描述为"OpenClaw for normal people"——把 Agent 能力降维到普通用户可用，与 Rene、Muse 形成 Personal Agent 三角信号。

• Assistant Benchmark 上线：71 个 AI 个人助理的公开评分卡，15 个维度横向评比——Personal Agent 赛道首个标准化评测框架。
